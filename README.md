# Family Asset Manager – GitHub Pages 배포 가이드

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html | 프로그램 본체 (FamilyAssetManager_v1.14.html과 동일) |
| manifest.webmanifest | 홈 화면 앱 설치 정보 (이름, 아이콘, 색상) |
| sw.js | 서비스 워커 – 오프라인 실행 캐시 |
| icon-192.png / icon-512.png / icon-maskable-512.png | 앱 아이콘 |
| .nojekyll | GitHub Pages의 Jekyll 처리 비활성화 |

## 배포 순서
1. GitHub에서 새 저장소 생성 (예: `family-asset`). 무료 계정은 **Public** 저장소여야 Pages 사용 가능.
2. **Add file → Upload files** 로 이 폴더의 파일 전체를 저장소 루트에 업로드 → Commit.
   - `.nojekyll`은 숨김 파일이라 탐색기에서 안 보일 수 있음. 없어도 동작에는 문제 없음.
3. **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1~2분 후 주소 생성: `https://<GitHub아이디>.github.io/family-asset/`

## 갤럭시 폰/태블릿에 설치
1. Chrome(또는 삼성 인터넷)으로 위 주소 접속.
2. 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**.
3. 이후 홈 화면 아이콘으로 실행 – 전체 화면, 오프라인에서도 실행됨.

## 데이터 관련 주의사항
- 입력 데이터는 **GitHub에 올라가지 않고**, 각 기기 브라우저(localStorage)에만 저장됨. 저장소가 Public이어도 자산 데이터는 공개되지 않음.
- 기기별로 데이터가 따로 저장됨 (폰 ↔ 태블릿 자동 동기화 없음). 프로그램의 **백업/복원** 기능으로 옮길 것.
- 브라우저 "사이트 데이터 삭제" 또는 앱 삭제 시 데이터가 지워지므로 정기적으로 백업 파일을 보관할 것.
- 저장소 이름(주소)을 바꾸면 다른 사이트로 인식되어 기존 데이터가 보이지 않음 → 바꾸기 전에 백업.

## 버전 업데이트 방법
1. 새 버전 HTML(예: v1.15)을 `index.html` 이름으로 덮어써서 업로드.
2. 버전 이름을 **두 곳** 같은 값으로 바꿔서 업로드 (다르면 설정 > 오프라인 저장 상태 화면이 정확하지 않음).
   - `sw.js`의 `const CACHE = PREFIX + 'v1.14';` → `'v1.15'`
   - `index.html` 끝부분의 `var APP_CACHE = 'fam-v1.14';` → `'fam-v1.15'`
3. 폰에서 앱을 한 번 열었다 닫았다 다시 열면 새 버전 적용 (온라인 상태 필요).

## 같은 주소에 다른 앱도 올린 경우 (중요)
- 같은 `○○.github.io` 주소에 올린 앱들(STEP Viewer, 3D Packing 등)은 브라우저의 오프라인 저장소를 **함께 씁니다**.
- 그래서 각 앱의 `sw.js`는 정리할 때 **자기 이름표(이 앱은 `fam-`)가 붙은 저장소만** 지워야 합니다. "내 이름이 아닌 건 전부 삭제" 방식은 다른 앱의 오프라인 저장본까지 지워서, GitHub에서 파일을 지우면 404가 뜨는 원인이 됩니다.
- 새 앱을 추가할 때는 그 앱 전용 이름표(예: `step-viewer-`, `packing-`)를 정하고, 저장소 이름이 겹치지 않게 하세요.

## 오프라인 저장 상태 확인
- 앱의 **설정 → 오프라인 저장 상태** 카드: 초록 점이면 오프라인 사용 가능, 주황이면 앱을 완전히 닫았다가 다시 열어야 함, 빨강이면 저장 안 됨.
- **상태 확인**: 서비스 워커·저장 파일·저장 공간을 자세히 보여줌 (문제가 있을 때 이 화면을 캡처해 두세요).
- **저장 초기화 후 다시 받기**: 앱 파일의 오프라인 저장본만 지우고 다시 받음. 입력한 자산 데이터·백업은 지워지지 않고, 같은 주소의 다른 앱 저장본도 건드리지 않음. (인터넷 필요)
- 안드로이드 앱(APK)이나 로컬 파일로 열었을 때는 이 카드가 나타나지 않음 (필요 없음).

## GitHub 저장소를 삭제/비공개로 바꿀 경우
- `sw.js`(fam-v1.13.1 이후)는 서버가 404를 돌려줘도 휴대폰에 캐시된 앱을 대신 실행함.
- 단, **삭제 전에** 각 기기에서 수정된 sw.js가 적용된 상태여야 함 (온라인에서 앱을 2회 이상 열기).
- 삭제 후에는 업데이트 불가, 브라우저가 캐시를 정리하면 앱이 사라질 수 있음 → 백업 파일 필수 보관.
- 가장 안정적인 방법은 저장소를 유지하는 것 (자산 데이터는 저장소에 올라가지 않음).

## 오프라인(인터넷 차단) 사용
- 외부 서버/CDN을 전혀 사용하지 않으므로 한 번 설치하면 인터넷 없이 모든 기능 동작.
- 비행기 모드: 즉시 캐시에서 실행. 방화벽 등으로 응답이 없는 망: 3초 후 캐시에서 실행 (fam-v1.14).
- 조건: 인터넷 되는 곳에서 설치 후 앱을 1회 이상 실행해 캐시가 저장되어 있을 것.
